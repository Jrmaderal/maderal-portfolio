# Rogelito Jr C. Maderal — Portfolio

## Pages

| Route       | Description                          |
|-------------|--------------------------------------|
| `/`         | Home – Hero with intro & photo       |
| `/about`    | About – Bio, skills, qualities       |
| `/projects` | Projects – Gallery with filters      |
| `/contact`  | Contact – Info + validated form      |

## Getting Started

```bash
pnpm install
pnpm run dev
```

## Scripts

- `pnpm run dev` – Start development server
- `pnpm run build` – Type-check and production build
- `pnpm run preview` – Preview production build
- `pnpm run lint` – Run ESLint

## Tech Stack Use

- React 19 + TypeScript
- Tailwind CSS 4
- Vite 8
- React Router 8

All personal content, project descriptions, and assets (`public/me.jpg`, project screenshots) are preserved from the original portfolio.
